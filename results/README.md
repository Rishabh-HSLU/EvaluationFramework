# Recorded benchmark results

**Current paper reference: [run #4](run4/README.md), O=200 and M=20.**

The [paper-number index](run4/paper_number_map.csv) connects reported scores,
intervals, seed summaries, dataset counts and configuration values to source
cells. The six run #4 CSVs include every outer and seed replicate.

The root benchmark_results.csv and aggregate_results.csv are convenient
canonical copies. Treat results/run4/ as the fixed paper reference when
comparing a new run; new computations can replace the canonical copies.

The four O40/MC0 files dated 20260916 are historical run #3 evidence, restored
after their tracking was removed. They are not the final paper intervals.
runs_manifest.csv retains the run history; some older exploratory/point-only
outputs are local and are not included in this reference bundle.

Parquet inputs remain outside Git. Their exact identities are recorded in
[panel_digests.txt](../docs/panel_digests.txt).
