fineval · evaluation framework for synthetic intraday market data

Does the generator reproduce the stylized facts of real markets?

A generative model (AIL) produces synthetic 1-minute equity prices. fineval scores how faithfully it reproduces four stylized facts of real markets, using real data's own sampling noise as the yardstick.

Stage 1–2 · datasets & curation

Every data loader object is shaped identically — 53,850 one-minute bars (138 NYSE sessions, Sep 2019 – Mar 2020, including the Feb–Mar 2020 volatility regime) × 600 tickers.

Curation

A ticker survives only if both sides cover ≥ 70% of the market clock (~37,700 valid returns). Missing bars stay honestly missing (NaN) — no imputation.

The four panels and their roles

Real ground truth

NYSE 1-minute prices. Serves as both the reference and — resampled against itself — the noise floor.

AIL evaluated

The generative model under evaluation. Full synthetic price paths on the same tickers and clock.

GBM --

Gaussian, memoryless, no seasonality. Possesses none of the four stylized facts — every metric must reject it.

MSV --

Two-factor log-volatility: slow fGn daily factor (H=0.9) × fast AR(1) intraday factor (~20-min). Purpose-built to excel at volatility clustering only.

Both baselines are generated directly on the curated clock with real's missing-data mask imposed, so all four panels enter the pipeline in the same shape and sparsity.

Known trade-off: the 70% coverage floor tilts the universe toward continuously-traded names — a survivorship bias shared with the standard literature, stated rather than hidden.

Stage 3 · preprocessing

Remove what is predictable(seasonality) — but only where it exists

Prices → log returns; overnight bars masked. Intraday seasonality (U-shaped variance profile) is divided out — but only where it exists.

Per-minute return variance across the trading day (relative to each panel's own mean)

table view
The decision rule. Dispersion of the profile (CV = std / mean) says whether seasonality exists:
CV > 0.3 → fit & divide out (FFF) · CV ≤ 0.3 → pass through
Each panel is deseasonalized on its own fitted profile (Flexible Fourier Form, Andersen & Bollerslev 1997) — never on real's.
Why conditional? GBM and MSV are seasonally flat. Dividing a flat series by real's U-shape would inject an artificial inverted smile into the baseline before any metric sees it — the evaluation would measure a preprocessing artifact. AIL, by contrast, has learned the real smile almost exactly, so removing each data loader object's own seasonality puts every generator on equal, non-seasonal footing.

Full-panel CVs: Real 0.944 · AIL 0.974 (both deseasonalized) · GBM ≈ 0.05 (passed through).

After this stage every metric sees only non-seasonal structure: what remains is the statistical fingerprint of the generator, not the shape of the trading day(microstructure).

Stage 4 · The stylized facts

What each metric measures

M2 · Volatility clustering — autocorrelation of |returns| (the featured example: what a metric actually sees)

table view

Real's ACF stays elevated for hours (long memory). Scored window: lags 60–390 — short-lag correlation is easy to fake; the long plateau is not. Session-confined only. GBM is zero by construction; MSV was tuned to match.

M1 · Unconditional heavy tails

Tail-weighted Wasserstein-1 distance between the pooled quantile functions of real and synthetic returns. The weight w(u) = 1 + λ[u−α + (1−u)−α] (α = 0.3, λ = 1) emphasizes both extreme tails while never ignoring the center.

M4 · Aggregational Gaussianity

Returns are heavy-tailed at 1 minute but approach Gaussian when aggregated. The feature is the excess-kurtosis decay curve κ(k)/κ(1) at scales k ∈ {1, 5, 15, 30} minutes, aggregated within sessions only. The metric scores the rate of convergence, not kurtosis itself.

M6 · Regime-conditional tails

Do tails get heavier when the market is turbulent? Each panel is split into five volatility regimes (rolling 60-minute σ, own quintiles); a generalized Pareto tail index ξ is fitted per regime. The gap is the weighted error of the ξ-curve, with extra weight on the two most stressed regimes.

Stage 5 · Resampling

Real data's own variability

For each of B=100 resamples, draw 200 tickers (with replacement) — twice from real, once per generator. The two real draws define the noise floor; each generator's distance to real is its gap. Sharing real draw A cancels draw-to-draw noise.

The score

s = mean(grr) / ( mean(grr) + mean(gsr) )

0.5 is perfection — the generator is exactly as far from real as real is from itself; no test can ask for more. Near 0: the gap dwarfs the noise floor — rejected.

Uncertainty & reproducibility

95% CI per cell from a paired bootstrap over the resample index — pairing preserves the correlation created by the shared real draw, giving narrow, honest intervals.

All draws come from fixed, per-cell random streams: one stream for real, one per generator, one per CI cell. Adding or removing a generator changes nothing for the others; the full table is exactly reproducible from one seed.

Why resample tickers, not days? The metrics pool across the cross-section, so ticker resampling probes exactly the sampling noise the score must be calibrated against.
